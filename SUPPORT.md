# Support

Skool Public Calendar is open-source software maintained by one person. Community support is best effort and has no guaranteed response time.

## Where to ask

- **Setup and usage questions:** use [GitHub Discussions](https://github.com/ctala/Sync2SkoolCalendar/discussions).
- **Reproducible defects:** open a bug report in [GitHub Issues](https://github.com/ctala/Sync2SkoolCalendar/issues).
- **Concrete feature proposals:** open a feature request in GitHub Issues.
- **Security vulnerabilities:** report privately through [GitHub Security Advisories](https://github.com/ctala/Sync2SkoolCalendar/security/advisories/new), never in a public issue.

## Before requesting help

1. Confirm the Skool community is public.
2. Read the README limitations and troubleshooting guidance.
3. Run the documented local checks or deployed smoke test.
4. Search existing issues and discussions.
5. Remove credentials, cookies, personal data, and private-community content from logs or examples.

## Support boundaries

The project can help with reproducible behavior in this repository. It cannot provide support for Skool accounts, Cloudflare billing or account policy, calendar-client refresh schedules, private communities, or unrelated Apify Actor workflows.
